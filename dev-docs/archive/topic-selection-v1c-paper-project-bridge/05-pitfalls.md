# 05 Pitfalls

- Do not create `PaperProjectBridge` from a ready package without human promotion authorization.
- Do not allow a gate-ready support artifact to bypass `PromotionDecision`.
- Do not drop accepted risks, conditions, blockers, or recheck refs at the bridge boundary.
- Do not let PaperProject edits rewrite topic-selection authority artifacts.
- Do not create multiple active bridges from one promotion decision.
