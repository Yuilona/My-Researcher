# 05 Pitfalls

## Do Not Repeat
- Do not revalidate unmet need inside v1b.
- Do not use value assessment as a promotion authorization.
- Do not treat draft package as promotion-ready.
- Do not let package narrative alter upstream question, claim, boundary, or evidence.
- Do not split v1b implementation before v1a contracts are stable.
- Do not let `ResearchSlice` planning silently accept stale upstream evidence or unresolved high-priority recheck.
- Do not let answerability planning invent feasibility evidence outside the selected ResearchSlice.
- Do not let replay metrics write production state or become evidence.
